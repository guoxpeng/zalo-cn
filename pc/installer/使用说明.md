# Zalo PC 汉化+翻译一键安装器 — 使用说明

双击 `Zalocn-PC-Installer.exe`，自动完成全部安装，不用手动拷文件、不用敲命令。**别人的电脑也能用**——exe 里内嵌了完整汉化工程，新电脑从零开始也能一次装完汉化+翻译。

---

## 一、安装前需要什么

安装器启动时会先检查，缺了就提示下载链接、退出，等装好再重跑：

| 需要的东西 | 用途 | 下载地址 |
|---|---|---|
| **Python** | 跑安装脚本 | https://www.python.org/downloads/ |
| **Node.js（LTS 长期支持版）** | 解包/打包 Zalo 的 asar 文件（自带 npx） | https://nodejs.org/ |
| **Zalo 已安装** | 要汉化翻译的目标软件 | https://zalo.me/ |

**装 Python 时注意**：安装界面务必勾选 **"Add Python to PATH"**（把 Python 加进系统路径），不勾的话安装器找不到 Python。

---

## 二、怎么安装

1. 下载 `Zalocn-PC-Installer.exe`（约 8MB）。
2. 双击运行。第一次运行 Windows 可能会弹 SmartScreen 警告（没签名的自制 exe 都会弹），点 **“更多信息” → “仍要运行”** 即可。
3. 安装器自动做 5 步，屏幕上逐行显示：
   1. **找 Zalo 安装目录**：先自动扫标准位置（`%LOCALAPPDATA%\Programs\Zalo`），找不到就看正在运行的 Zalo 在哪，还找不到就弹文件夹选择框，**让你自己指定 Zalo 所在文件夹**（选里面有 `Zalo-26.11.12` 这类版本文件夹的那个；选错了会提示重选）。
   2. **找 work 文件夹**：先看 exe 自身目录，再找 `D:\project\zalo\zalopc\work`，再全盘搜索；新电脑都没有，就在 `%LOCALAPPDATA%\Zalocn\work` 新建一个。
   3. **写入汉化工程文件**：把 exe 里内嵌的完整工程（安装脚本 + 汉化脚本 + 词库 + 翻译注入 + 守护脚本）写进 work 文件夹，旧文件直接覆盖。
   4. **跑安装**：Zalo 没汉化就走全流程，汉化+翻译一次装完；已经汉化就只补翻译注入；替换 asar → 重启 Zalo。输出实时显示在窗口里。
   5. **开机守护**：问要不要安装开机守护（Zalo 更新后自动重打，推荐装）。装就在 Startup 文件夹建快捷方式。
4. 跑完按回车退出。Zalo 应该已经自动重启并带上汉化+翻译。

**装之前请先关掉 Zalo**（任务栏右键退出）。Zalo 运行时它的文件被锁定，替换不了。

## 三、装好后怎么用

- **收到的消息**：自动翻成中文，原文在上、译文在下框。
- **自己发的越南语**：也自动翻成中文（方便核对自己发了什么；自己发的中文不翻）。不想翻可以在设置里关掉。
- **发消息**：输入框里打中文，点「译」按钮，填回越南语（默认中文一行 + 越南语一行；不自动发，检查后自己点发送）。
- **调设置**：点「译」按钮旁边的 **齿轮按钮**，弹出翻译设置面板——接收语言 / “译”按钮语言 / 自动翻译开关 / 翻译自己消息开关 / “译”按钮同时保留原文 / API 地址·密钥·模型 / 翻译提示词 / 测试当前配置。改完自动保存，立即生效。

## 四、work 文件夹是什么

**work 文件夹是“车间”**，放汉化脚本、翻译注入脚本、词库、打包工具、日志。安装脚本从这里工作：检测 Zalo 状态 → 生成汉化包 → 打翻译补丁 → 把成品 `app.asar` 替换进 Zalo 安装目录。Zalo 更新后，开机守护每 10 分钟检查一次，自动重打。

**为什么 work 文件夹不在 Zalo 主文件夹下？**

- Zalo 主文件夹是 Zalo 自己的安装目录，Zalo 一更新就整个替换版本文件夹（比如 `Zalo-26.11.12` 换成 `Zalo-26.11.13`），放里面的东西会被清空。
- 动 Zalo 自己的目录也有风险。

所以工程文件单独放，**只有成品 `app.asar` 才进 Zalo 目录**。这样 Zalo 怎么更新，工程都不受影响，守护能自动重打。

**其他人的电脑上有 work 文件夹吗？**

没有。这是专用的工程文件夹，只有装过本安装器的电脑上才有。别的 Zalo 用户没有这个东西，他们的 Zalo 就是原版。

## 五、常见问题

**Q：双击 exe 没反应 / 一闪而过？**
A：先确认 Python 和 Node.js 都装了（见第一节）。缺了安装器会提示下载链接，装完再重跑。

**Q：提示“没找到 Zalo 安装目录”？**
A：安装器会弹文件夹选择框，让你自己指定 Zalo 所在文件夹。选里面有 `Zalo-26.11.12` 这类版本文件夹的那个（一般是 `C:\Users\你的用户名\AppData\Local\Programs\Zalo`）。选错了会提示重选。

**Q：Zalo 更新后汉化/翻译没了？**
A：正常。Zalo 更新会换掉整个版本文件夹。装了开机守护的话，等 10 分钟会自动重打；没装守护就重新双击安装器跑一次。

**Q：怎么更新到新版翻译？**
A：重新下载最新版 `Zalocn-PC-Installer.exe`，双击跑一次就行，会自动覆盖旧文件、补上新版翻译。

**Q：出问题了怎么恢复？**
A：跑 work 文件夹里 `translate\restore-translate.ps1` 可一键恢复；或把 work 文件夹里的 `auto_patch.log` 发给开发者看。

**Q：安装器会联网吗？会传我的聊天记录吗？**
A：安装过程不联网（词库和脚本都在 exe 里）。翻译功能走你自己配的大模型 API（默认 bilibili 公开接口），只把要翻译的那条消息发给翻译接口，和任何翻译软件一样；安装器本身不收集、不上传你的聊天记录。
