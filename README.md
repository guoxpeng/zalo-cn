# Zalo 汉化（ZaloZH）

> 一个把 Zalo 界面从越南语 / 英文变成简体中文的 Xposed 模块。
> 在越南打拼的中国朋友，看不懂越南语 Zalo 的，装上它，界面就顺眼多了。

---

## 这个东西是干嘛的？

相信在越南的各位都有体会：Zalo 是这边人人都用的聊天软件（就像国内的微信），但界面全是越南语和英文，看不懂、点错、找不到设置，真的很抓狂。

这个模块就是干这个的：**把 Zalo 界面上的英文和越南语文本，全部替换成简体中文**。装好之后打开 Zalo，设置、隐私、账户与安全、聊天附件、发送定位、安全检查……这些页面基本都变中文了，看着心里踏实。

## 它能做到什么程度？

- **12165+ 条翻译**，覆盖 Zalo 资源表里 99.6% 能翻译的界面文本。
  设置、隐私、通知、账户与安全、我的文档、聊天 "+" 菜单、发送定位、安全检查、**日记（Timeline）**……这些页面**全覆盖**。
- **HTML 富文本也能翻**：带 `<b>`/`<a>` 标签和占位符的文本（如日记页"%d 人赞了这条动态"、"发布在相册 %s 中"）同样完整汉化，标签和格式保留不变。
- **多种 Hook 路径**，什么犄角旮旯的文本都能抓到：
  - 标准资源路径（`Resources.getText / getString` 等）
  - `setText`（单参 + 双参）——Zalo 新版很多自定义按钮走的是双参版本，别的模块只 hook 单参就会漏，我们把两条路都堵上了
  - `setHint`——输入框里的灰色提示文字（比如登录页的"密码"）
  - `ZOMText / ZOMText2`——Zalo 有个叫 **ZInstant** 的东西，是服务器下发动态 UI，"安全检查"这类页面就是它画的，文本压根不在 App 里，我们也给覆盖了
- **原文→中文全量映射**：内置英文原文 9415 条 + 越南语原文 9307 条。就算文本绕过了资源系统（比如服务器下发、代码里拼出来的），只要界面出现，也能翻译。

## 安全优势（为什么可以放心用）

这是这个模块跟那些"外挂"最本质的区别，我一条条讲清楚：

- **纯界面翻译**：只替换屏幕上显示的文本，**不碰**网络请求、账号数据、聊天记录、登录态、加密逻辑。说白了就是个"换皮"，底子完全不动。
- **不改 Zalo 本体**：不重打包、不改 APK 文件，只是运行时注入一层翻译，卸载模块、强制停止 Zalo 就完全恢复原样，不留任何痕迹。
- **模块自己不联网**：不会把你的任何数据传出去，没有后台服务，不申请多余权限。
- **翻译都在本地**：所有翻译数据打包在模块 APK 里，离线也能用，不依赖任何服务器。
- **异常自动兜底**：万一翻译过程中出点什么小问题，模块只会静默跳过那一条文本，绝不会把 Zalo 搞崩。

## 封号风险（把丑话说在前面）

说实话，**"绝对不会封号"这种话没人敢保证**。Zalo 官方条款确实不允许修改客户端，理论上任何修改版都有被风控的风险。

但可以负责任地告诉你这个模块的风险等级：

- 它**不发任何修改过的请求、不改任何账号数据、不碰服务器通信**——风控系统主要盯的是账号行为和流量特征，纯改界面显示文本基本不在这类检测范围内。
- 它跟那种改协议抢红包、自动回复、多开分身的外挂**完全不是一回事**，那些才是真正的高危操作。

**给你个实在建议**：心里没底的话，先用小号装上用几天，觉得稳了再换主号。真出问题（概率极低），卸载模块即可恢复，账号不会留有任何修改痕迹。

## Zalo 版本要求

- **实测版本**：Zalo **26.08.01（26.8.1）**，已在 **Android 9 模拟器 + Android 真机**上完整验证：登录、引导页、设置、隐私、我的文档、聊天附件等页面全中文，**运行稳定、无崩溃、无异常**（真机实测：钱包、发现页绝大部分内容已汉化）。
- **兼容性**：模块 hook 的是系统层方法（`Resources.getText`、`setText`、`setHint` 等），**不依赖具体 Zalo 版本号**，所以 26.x 新老版本大概率都能用。
- **风险提示**：Zalo 大版本重构（比如换了渲染框架）可能导致个别页面文本失效，等模块更新即可；不影响 Zalo 本身功能。
- **系统要求**：Android 8.1 及以上；需要 Root + LSPosed 或 Vector 框架。

还没 Root？那得先搞定 Root 和 LSPosed 再来装这个，百度一下自己手机型号的教程就行，这里不展开。

## 怎么安装？

跟着走，三步搞定：

1. **安装模块 APK**（名字叫 `Zalo 汉化`，包名 `com.zalocn`），直接点开装就行，跟装普通 App 一样。
2. **打开 LSPosed / Vector Manager**，进"模块"页：
   - 找到 **Zalo 汉化**，把它**启用**（开关打开）
   - 点进模块详情，**作用域（Scope）勾选 Zalo（com.zing.zalo）**——这一步很容易漏，漏了就不生效
3. **强制停止 Zalo，再重新打开**。注意不是后台划掉，是"强制停止"（应用信息 → 强制停止），因为模块只在 Zalo 进程重新创建的时候才会注入。
4. 如果装完发现模块显示"未启用"，命令行跑一下：`adb shell pm enable com.zalocn`

就这。打开 Zalo，界面就是中文了。

## 常见问题（FAQ）

**Q：装了模块，Zalo 还是英文，咋回事？**
A：九成是这两种情况：
1. 作用域没勾 Zalo（回到第 2 步检查）；
2. 改完没强制停止 Zalo 就重开了（回到第 3 步）。
  还不行就重启一下手机，基本都能解决。

**Q：会不会封号？**
A：看上面"封号风险"那一节。总结一句：风险极低但不是零，介意就别用，用小号先试最稳妥。

**Q：模块装上会影响 Zalo 登录、收消息吗？**
A：不影响。它只是翻译显示文字，登录、聊天、收付款该怎么样还怎么样。

**Q：有个别页面还是越南语/英文？**
A：把页面名字或截图发给我，我针对性补翻译。毕竟 12000 条翻译靠机翻+人工校对，难免有个别漏网之鱼。

**Q：升级 Zalo 之后模块还有效吗？**
A：大概率有效，因为 hook 的是系统层方法，不依赖具体版本。但如果 Zalo 大改版导致失效，等模块更新就行。

**Q：想卸载怎么办？**
A：在 LSPosed/Vector Manager 里关掉模块，然后卸载 APK，或者直接卸载 APK 再 force-stop Zalo，就回到原样了，不留任何痕迹。

## 原理（给好奇的人）

Zalo 的界面文本大部分存在资源表（resources.arsc）里，读取时统一走 `Resources.getText(int)` 这些方法。模块 hook 住这些方法，按资源 ID 找到对应的中文直接返回；再 hook 住 `setText / setHint / ZInstant`，兜底覆盖那些不走资源系统的文本（Zalo 新版用了大量自定义组件和服务器下发 UI）。

翻译数据放在 `assets/translations.json`（资源名→中文）和 `assets/src_map.json`（原文→中文）里，想自己加翻译、改翻译，直接编辑这两个文件重新构建就行。

## 从源码构建（给开发者）

环境：JDK 21、Android SDK build-tools 36.0.0、platforms android-34、git-bash（Windows）。

```bash
cd build
bash build_module.sh   # 产物：zalozh_hanhua.apk
```

构建脚本做的事：javac 编译 `MainHook.java` → d8 打包成 dex → 组装 APK（保留空壳 classes.dex、resources.arsc 不压缩）→ zipalign + apksigner 签名。
