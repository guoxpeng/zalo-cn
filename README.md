# Zalo 汉化

> 把 Zalo 界面从越南语 / 英文翻译成简体中文的 Xposed 模块。
> 在越南打拼的中国朋友，装上它，界面就顺眼多了。

## 功能

- **12000+ 条翻译**，覆盖设置、隐私、账户与安全、通知、我的文档、聊天附件、发送定位、日记（Timeline）、安全检查、钱包等页面
- **服务器下发的文本也能翻**（ZInstant 动态 UI，如安全检查页、小程序分类）
- **H5 网页页面也覆盖**（v1.7 起）：钱包的 Activity（交易记录）、Card（卡）等 WebView 页面，加载后自动注入翻译，动态内容同样生效
- **纯 UI 翻译**：只替换屏幕显示文字，不改 Zalo 本体、不碰网络请求与账号数据、模块不联网、翻译全在本地离线可用

## 支持版本

- 实测 **Zalo 26.08.02（26.8.2）** 及 26.08.01（26.8.1），Android 真机 + 模拟器验证，运行稳定无异常
- hook 的是系统层方法，不依赖具体版本号，26.x 新老版本大概率通用
- 系统要求：Android 8.1+，需 Root + LSPosed / Vector

## 安装

1. 安装模块 APK（包名 `com.zalocn`，应用名「Zalo 汉化」）
2. 打开 LSPosed / Vector Manager → 启用模块 → **作用域勾选 Zalo（com.zing.zalo）**（这步漏了不生效）
3. **强制停止 Zalo 再重开**（模块只在进程新建时注入）

## 常见问题

**装了没效果？** 九成是作用域没勾 Zalo，或改完没强制停止 Zalo。重启手机基本能解决。

**会封号吗？** 风险极低但不是零——模块只改显示文本，不发修改请求、不碰服务器通信，跟改协议的外挂不是一回事。介意就用小号先试几天。

**影响登录、收消息吗？** 不影响，它只是"换皮"。

**有页面还是英文？** 把页面名或截图发我，针对性补翻译。
